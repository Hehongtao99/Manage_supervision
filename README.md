# 体育跑步管理监督系统

该项目是一个完整的体育跑步管理监督系统，包含前后端分离架构，实现了用户管理、跑步记录、社交互动、即时聊天等功能。

## 技术栈

### 前端技术栈

- **核心框架**：Vue 3 + TypeScript
- **状态管理**：Pinia
- **路由管理**：Vue Router 4
- **UI组件库**：Element Plus
- **HTTP请求**：Axios
- **构建工具**：Vite
- **WebSocket通信**：SockJS + STOMP.js
- **数据可视化**：ECharts + Vue-ECharts
- **样式预处理器**：Sass

### 后端技术栈

- **核心框架**：Spring Boot 3.0.2
- **ORM框架**：MyBatis-Plus 3.5.3.1
- **数据库**：MySQL
- **安全认证**：JWT (JSON Web Token)
- **密码加密**：BCrypt
- **WebSocket支持**：Spring WebSocket
- **依赖注入**：Spring IoC
- **AOP支持**：Spring AOP
- **RESTful API**：Spring MVC

## 功能实现

### 1. 用户认证与授权

- **技术实现**：
  - **JWT认证流程**：用户登录时，后端验证用户凭据，生成包含用户ID和角色的JWT令牌，前端存储令牌并在后续请求中通过Authorization头部传递
  - **密码安全**：使用BCrypt单向哈希算法加密密码，存储哈希值而非明文
  - **拦截器机制**：实现JWTInterceptor拦截未认证请求，验证令牌有效性
  - **自定义注解**：通过@RequireRole注解实现方法级权限控制
  - **前端状态管理**：使用Pinia存储用户认证状态，实现路由守卫进行页面访问控制
  
- **功能描述**：
  - 用户注册、登录、注销
  - 基于角色的权限管理（ADMIN/SUPERVISOR/USER）
  - 用户信息的更新与密码修改
  - 令牌验证与刷新机制

### 2. 聊天系统

- **技术实现**：
  - **WebSocket连接**：后端通过Spring WebSocket配置，创建WebSocketConfig配置类，定义端点和消息代理
  - **消息订阅**：使用STOMP协议，定义/topic和/queue前缀区分广播和点对点消息
  - **前端实现**：使用SockJS和STOMP.js客户端库实现连接管理，消息订阅与发送
  - **消息持久化**：使用MySQL存储消息历史，通过conversations和chat_messages表设计实现
  - **文件传输**：通过multipart/form-data上传文件，后端处理并存储，返回访问URL
  - **状态同步**：使用心跳机制维护用户在线状态，通过事件广播通知状态变更
  
- **功能描述**：
  - 实时一对一聊天
  - 消息发送与接收（包括文本和文件）
  - 在线状态监测
  - 未读消息统计
  - 会话列表管理

### 3. 社交功能模块

- **技术实现**：
  - **数据结构设计**：创建posts、comments、likes表存储社交内容和互动数据
  - **关系映射**：使用MyBatis-Plus实现多表关联查询，处理用户间关系
  - **图片处理**：前端使用FormData上传图片，后端进行压缩和存储
  - **分页加载**：使用MyBatis-Plus的Page对象实现分页查询，前端实现滚动加载
  - **权限检查**：每次内容访问时检查用户关系（好友、公开等）决定内容可见性
  - **异步加载**：前端使用Axios发起异步请求，加载社交动态内容
  - **转发功能**：在数据库中通过original_post_id字段关联原始帖子，实现转发关系追踪
  
- **功能描述**：
  - 发布朋友圈动态（支持文字、图片）
  - 点赞、评论交互
  - 转发功能
  - 个人动态管理
  - 权限控制（根据用户关系控制内容可见性）

### 4. 跑步记录管理

- **技术实现**：
  - **数据持久化**：使用running_records表存储跑步记录，running_preferences表存储用户偏好
  - **数据处理**：后端使用Java 8 Stream API聚合处理跑步数据，计算统计指标
  - **图表渲染**：前端使用ECharts库创建多种图表（折线图、饼图、柱状图）展示数据
  - **时间分析**：使用date-fns库处理日期计算，实现按日、周、月数据分组
  - **动态表单**：前端表单通过v-model双向绑定，实现跑步数据实时验证与提交
  - **成就系统**：基于跑步数据自动计算用户成就，通过数据库触发器实现
  
- **功能描述**：
  - 记录用户跑步数据
  - 个人跑步统计与分析
  - 跑步数据看板
  - 历史记录查询
  - 个性化跑步偏好设置

### 5. 督导管理系统

- **技术实现**：
  - **关系管理**：通过teacher_student_relations表建立师生关系
  - **权限控制**：使用Spring AOP实现方法拦截，确保督导只能访问其管理的学生数据
  - **数据筛选**：使用MyBatis-Plus的QueryWrapper构建复杂查询条件
  - **角色视图**：前端基于用户角色动态渲染不同视图组件
  - **批量操作**：实现批量分配学生、批量消息通知等功能
  - **进度监控**：通过定时任务统计学生跑步完成情况，生成报表
  
- **功能描述**：
  - 教师-学生关系管理
  - 学生跑步进度监控
  - 督导员管理学生
  - 管理员对整个系统的管理

### 6. 文件上传与管理

- **技术实现**：
  - **文件上传**：前端使用FormData封装文件，通过Axios发送POST请求
  - **文件处理**：后端使用MultipartFile接收文件，进行验证、重命名和存储
  - **类型验证**：通过检查文件MIME类型和扩展名防止上传恶意文件
  - **存储结构**：按用户ID和时间创建目录结构，避免文件名冲突
  - **文件服务**：配置静态资源映射，提供文件访问URL
  - **图片处理**：对上传图片进行压缩和尺寸调整，减少存储空间和加载时间
  
- **功能描述**：
  - 头像上传
  - 聊天文件传输
  - 朋友圈图片上传
  - 文件类型验证与大小限制

### 7. 好友管理

- **技术实现**：
  - **关系模型**：设计friend_relations表存储用户间关系，status字段标记关系状态
  - **请求处理**：实现好友申请、接受、拒绝和删除的完整流程
  - **实时通知**：通过WebSocket推送好友请求和状态变更通知
  - **前端交互**：使用Element Plus组件创建好友列表、请求管理界面
  - **权限联动**：好友关系变更自动影响社交内容权限和聊天功能
  - **搜索功能**：实现用户搜索，支持按用户名、昵称或真实姓名查找用户
  
- **功能描述**：
  - 添加/删除好友
  - 好友请求管理
  - 好友列表查看
  - 好友关系影响社交内容可见性

### 8. 数据可视化

- **技术实现**：
  - **图表组件**：使用Vue-ECharts封装ECharts，创建可复用图表组件
  - **数据转换**：后端API返回格式化数据，前端转换为ECharts配置
  - **响应式图表**：监听窗口大小变化，自动调整图表尺寸
  - **交互设计**：实现图表联动，点击切换不同维度数据展示
  - **主题定制**：根据系统主题自定义图表颜色和样式
  - **导出功能**：支持图表数据导出为CSV或图片格式
  
- **功能描述**：
  - 跑步数据图表展示
  - 管理员控制台数据统计
  - 用户活跃度分析
  - 个人成就统计

### 9. 系统管理功能

- **技术实现**：
  - **后台路由**：基于角色的路由控制，管理员专属功能菜单
  - **数据管理**：使用MyBatis-Plus实现基础CRUD操作
  - **表格组件**：基于Element Plus的el-table组件，实现排序、筛选和分页
  - **批量操作**：支持选择多个用户进行批量操作
  - **安全控制**：管理员操作记录日志，敏感操作需二次确认
  - **系统配置**：动态修改系统参数，无需重启应用
  
- **功能描述**：
  - 用户管理（创建、编辑、禁用账户）
  - 角色权限管理
  - 系统日志查看
  - 基础数据管理

### 10. 前端数据交互

- **技术实现**：
  - **请求封装**：基于Axios创建请求实例，统一处理请求头和错误响应
  - **拦截器配置**：请求拦截器添加认证令牌，响应拦截器处理错误和令牌过期
  - **状态管理**：使用Pinia存储和管理应用状态，实现组件间数据共享
  - **表单验证**：基于Element Plus表单验证规则，实现客户端数据验证
  - **缓存策略**：本地存储用户数据和令牌，优化访问体验
  - **事件总线**：使用mitt库实现组件间通信，触发和响应全局事件
  
- **功能描述**：
  - 实时数据加载与更新
  - 表单验证与提交
  - 分页加载
  - 数据过滤与排序

## 系统特点

1. **高内聚低耦合**：采用模块化设计，前后端分离
2. **响应式设计**：适配不同设备的界面布局
3. **实时通信**：基于WebSocket的即时消息系统
4. **权限控制**：细粒度的功能和数据访问控制
5. **数据可视化**：直观展示统计数据和运动记录
6. **安全性**：采用JWT认证和BCrypt密码加密
