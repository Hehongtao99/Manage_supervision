# 旅游管理系统数据导入说明

本目录包含旅游管理系统的示例数据，主要包括以下几类数据：

1. 省市区地区数据 - `regions_data.sql`
2. 景区数据 - `scenic_spots_data.sql`
3. 酒店数据 - `hotels_data.sql`
4. 数据导入主文件 - `insert_all_data.sql`

## 数据概览

- 地区数据：包含10个省级区域，每个省下设多个市级和区县级地区，共57条记录
- 景区数据：包含全国20个知名景区，涵盖了5A、4A级景区
- 酒店数据：包含22家与景区关联的酒店，大部分为四星和五星级酒店

## 导入方法

### 方法一：使用MySQL命令行工具

1. 进入MySQL命令行
```bash
mysql -u username -p
```

2. 选择目标数据库
```sql
USE trave;
```

3. 执行主SQL文件
```sql
SOURCE /path/to/insert_all_data.sql;
```

### 方法二：使用GUI工具（如Navicat、MySQL Workbench等）

1. 连接到目标数据库
2. 打开SQL编辑器
3. 打开并执行`insert_all_data.sql`文件

## 注意事项

- 导入前请确保数据库`trave`已创建，并且表结构已正确创建
- 数据导入脚本会先清空相关表的现有数据，请谨慎操作
- 图片URL使用的是公开可访问的网络图片，可能会因第三方网站变更而失效
- 导入数据前建议先备份数据库

## 数据关系说明

- 酒店数据关联了地区(省市区)和景区
- 景区数据关联了地区(省市区)
- 地区数据采用了三级结构：省-市-区县
