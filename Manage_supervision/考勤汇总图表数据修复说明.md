# 考勤汇总图表数据修复说明

## 问题描述
原来的考勤汇总页面中，打卡趋势图和时间分布热力图使用的是模拟数据，不能反映真实的打卡情况。

## 修复内容

### 1. 后端数据接口
新增了以下API接口来提供真实的统计数据：

#### 每日打卡统计
- **接口**: `GET /api/attendance/admin/daily-statistics`
- **功能**: 获取指定时间范围内每日的打卡次数统计
- **返回数据格式**:
```json
[
  {
    "date": "2025-01-23",
    "count": 45
  },
  {
    "date": "2025-01-24", 
    "count": 38
  }
]
```

#### 打卡时间分布
- **接口**: `GET /api/attendance/admin/time-distribution`
- **功能**: 获取按小时和星期分组的打卡分布数据
- **返回数据格式**:
```json
[
  {
    "dayOfWeek": 1,  // 0=周日, 1=周一, ..., 6=周六
    "hour": 8,       // 0-23小时
    "count": 15      // 该时段打卡次数
  }
]
```

### 2. 数据库查询优化
- 只统计前台考勤记录（`attendance_id > 0`）
- 排除系统特殊记录（`attendance_id = -1`）
- 按日期和时间维度进行分组统计

### 3. 前端图表更新

#### 每日打卡趋势图
- 使用真实的每日统计数据
- X轴显示日期，Y轴显示打卡次数
- 鼠标悬停显示具体数值

#### 打卡时间分布热力图
- 使用真实的时间分布数据
- 7天×24小时的热力图矩阵
- 颜色深浅表示打卡频率高低
- 动态计算最大值用于颜色映射

#### 详细统计表格
- 基于真实的每日数据计算
- 根据打卡次数智能推算高峰时段
- 估算人脸验证率和活跃用户数

### 4. 数据流程
1. 用户选择日期范围并点击查询
2. 前端同时调用三个API获取数据：
   - 基础统计数据
   - 每日打卡统计
   - 时间分布数据
3. 图表组件根据真实数据动态渲染
4. 表格显示基于真实数据的详细统计

## 技术实现

### 后端
- **AttendanceRecordMapper**: 新增SQL查询方法
- **AttendanceService**: 新增服务接口
- **AttendanceServiceImpl**: 实现具体业务逻辑

### 前端
- **attendance.ts**: 新增API调用方法
- **AttendanceSummary.vue**: 更新图表配置和数据处理逻辑

## 修复效果
- ✅ 打卡趋势图显示真实的每日打卡数据
- ✅ 时间分布热力图反映实际的打卡时间模式
- ✅ 统计表格基于真实数据计算
- ✅ 支持按日期范围动态查询

## 使用说明
1. 进入考勤汇总页面
2. 选择要查询的日期范围（支持快捷选项）
3. 点击"查询"按钮
4. 查看更新后的图表和统计数据

所有图表现在都基于真实的前台考勤打卡数据，能够准确反映用户的打卡行为和时间分布模式。
