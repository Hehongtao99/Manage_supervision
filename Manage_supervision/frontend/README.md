# 学生管理系统前端文档

本文档详细介绍了学生管理系统前端的架构和各个组件功能。

## 项目结构概览

前端采用Vue 3框架开发，使用TypeScript进行类型管理，Vite作为构建工具，主要包含以下模块：

```
frontend/
├── public/              - 静态资源目录
├── src/                 - 源代码目录
│   ├── api/             - API接口定义
│   ├── assets/          - 静态资源文件（图片、字体等）
│   ├── components/      - 可复用组件
│   ├── layouts/         - 布局组件
│   ├── router/          - 路由配置
│   ├── services/        - 服务层
│   ├── stores/          - 状态管理（Pinia）
│   ├── types/           - TypeScript类型定义
│   ├── utils/           - 工具函数
│   ├── views/           - 页面视图组件
│   ├── App.vue          - 根组件
│   ├── main.ts          - 应用入口文件
│   ├── style.css        - 全局样式
│   └── vite-env.d.ts    - Vite环境类型声明
├── index.html           - HTML模板
├── package.json         - 项目依赖配置
├── tsconfig.json        - TypeScript配置
├── vite.config.ts       - Vite构建配置
└── README.md            - 项目说明文档
```

## 核心文件说明

### 入口文件

#### `main.ts`
- **功能说明**：应用程序的入口文件
- **主要内容**：创建Vue应用实例，挂载全局插件和组件，初始化应用
- **技术要点**：Vue 3 Composition API，Pinia状态管理，Vue Router路由管理

#### `App.vue`
- **功能说明**：应用的根组件
- **主要内容**：定义应用的整体布局结构，包含路由视图和全局组件
- **技术要点**：Vue 3组件结构，动态布局管理

### 路由管理 (router)

#### `index.ts`
- **功能说明**：路由配置文件
- **主要内容**：定义应用的所有路由规则，包括路径、组件映射、路由守卫等
- **路由分组**：
  - 公共路由（登录、注册、首页）
  - 管理员路由
  - 教师路由
  - 学生路由
  - 家长路由
  - 督导路由
- **路由守卫**：实现基于角色的访问控制，未登录用户重定向到登录页面
- **路由模式**：使用HTML5 History模式

### 状态管理 (stores)

#### `user.ts`
- **功能说明**：用户状态管理
- **主要内容**：管理用户登录状态、个人信息、权限等数据
- **核心方法**：
  - 用户登录/登出
  - 获取用户信息
  - 更新用户资料
  - 权限检查
- **状态持久化**：使用localStorage存储令牌，实现会话保持

#### `chat.ts`
- **功能说明**：聊天状态管理
- **主要内容**：管理即时通讯相关的状态和行为
- **核心方法**：
  - 聊天会话管理
  - 消息收发处理
  - 未读消息统计
  - 在线状态管理
- **实现技术**：WebSocket实时通信，消息缓存

## 核心业务流程

### 用户认证流程
1. 用户访问系统，路由守卫检查登录状态
2. 未登录用户重定向到登录页面
3. 用户提交账号密码，调用认证API
4. 登录成功后获取用户信息和权限
5. 根据用户角色重定向到相应的首页

### 权限控制流程
1. 用户登录后，获取并存储用户角色信息
2. 路由配置中包含每个路由需要的角色权限
3. 路由守卫在导航时检查用户是否具有访问权限
4. 菜单组件根据用户角色动态生成可见菜单项
5. 页面组件内部也可以基于用户角色控制功能可用性

### 数据请求流程
1. 组件内调用API模块中定义的方法
2. API方法通过request工具发送HTTP请求
3. 请求拦截器自动添加认证令牌
4. 响应拦截器处理常见错误（如认证失效）
5. 数据返回组件进行处理和展示

### 即时通讯流程
1. 用户登录成功后建立WebSocket连接
2. 聊天状态管理器监听消息事件
3. 收到新消息时更新聊天记录和未读计数
4. 发送消息时通过WebSocket发送并存储到本地记录
5. 消息状态（发送中、已发送、已读）实时更新

### 表单处理流程
1. 组件内定义表单数据和验证规则
2. 用户输入触发实时验证
3. 提交前进行表单完整性验证
4. 验证通过后调用API提交数据
5. 根据API响应显示成功或错误信息

## 实现细节

### 响应式设计
- 使用Flexbox和Grid布局，适应不同屏幕尺寸
- 媒体查询针对手机、平板和桌面设备优化显示
- 组件自适应容器大小，保持良好的可用性

### 状态管理策略
- 全局状态（用户信息、应用设置）使用Pinia管理
- 组件局部状态使用Vue的响应式API管理
- 持久化状态存储在localStorage或sessionStorage
- 临时状态仅在内存中保存

### 性能优化
- 路由懒加载，按需加载页面组件
- 虚拟滚动处理长列表数据
- 图片懒加载和适当的缓存策略
- 组件粒度适中，避免过度拆分和频繁重渲染

### 错误处理
- 全局错误捕获机制
- API请求统一错误处理
- 表单验证错误友好提示
- 异常状态的优雅降级和恢复

## 部署与配置

```bash

npm install

# 启动开发服务器
npm run dev
```

### 生产构建
```bash
# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

### 环境变量配置
主要通过`.env`文件配置不同环境的参数：
- API基础URL
- 静态资源路径
- 功能开关
- 日志级别

### 跨域配置
开发环境通过Vite的代理功能解决跨域问题：
```javascript
// vite.config.ts
export default defineConfig({
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:8081',
        changeOrigin: true
      }
    }
  }
})
```

## 扩展与维护

### 添加新页面
1. 在`views`目录对应的角色文件夹中创建Vue组件
2. 在`router/index.ts`中添加路由配置
3. 如需API交互，在`api`目录添加相应方法
4. 如需状态管理，在`stores`目录添加或扩展store

### 添加新组件
1. 在`components`目录创建新组件
2. 设计良好的props和events接口
3. 编写完善的类型定义
4. 考虑组件的可复用性和可扩展性

### 样式管理
1. 全局样式定义在`style.css`中
2. 组件局部样式使用`<style scoped>`
3. 主题变量集中管理，便于定制
4. 遵循命名约定，避免样式冲突
