# 社交模块API需求文档

## 转发权限检查API

### 接口说明
新增API接口，用于检查用户是否有权限转发特定帖子。

### 请求方式
- **HTTP方法**: GET
- **URL路径**: `/api/social/post/{postId}/check-forward-permission`

### 请求参数
- **路径参数**:
  - `postId`: 要转发的帖子ID (整数)

- **请求头**:
  - 必须包含授权令牌 (`Authorization: Bearer {token}`)

### 响应内容
- **成功响应** (HTTP状态码 200):
  ```json
  {
    "code": 200,
    "message": "有权限转发",
    "data": {
      "canForward": true
    }
  }
  ```

- **失败响应** (HTTP状态码 403):
  ```json
  {
    "code": 403,
    "message": "无权限查看或转发该帖子，用户要有能够转发帖子的权限",
    "data": null
  }
  ```

### 权限检查逻辑
后端应当实现以下权限检查逻辑：
1. 检查用户是否已登录
2. 检查用户是否有转发权限（根据系统角色/权限设置）
3. 检查帖子是否存在
4. 检查帖子的可见性设置是否允许当前用户查看
5. 检查帖子是否允许转发（如果有特殊设置）
6. 检查用户与帖子作者的关系（如是否是好友）

只有当所有条件都满足时，才返回成功响应；否则返回失败响应，并在message中说明具体原因。

## 实现建议
前端已经添加了对应的API调用方法，后端需要实现此API端点以确保转发功能正常工作。此API将在用户点击转发按钮时被调用，用于预先检查权限，避免用户在填写转发内容后才发现没有权限。
