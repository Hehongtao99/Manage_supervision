#### 2.2.1 代码覆盖率测试

**单元测试覆盖范围：**
- Service层方法：≥80%
- Controller层方法：≥70%
- Mapper层方法：≥90%

**测试示例：**
```java
@Test
public void testAddRunningRecord() {
    // 准备测试数据
    RunningRecordRequest request = new RunningRecordRequest();
    request.setDistance(new BigDecimal("5.0"));
    request.setDuration(30);
    request.setPace("6:00");
    
    // 执行测试
    RunningRecordResponse response = runningRecordService.addRecord(1L, request);

    assertEquals(new BigDecimal("5.0"), response.getDistance());
    assertEquals(30, response.getDuration());
}
```

#### 2.2.2 路径覆盖测试

**关键路径测试：**
1. 登录流程
   - 路径1：用户名错误 → 返回错误信息
   - 路径2：密码错误 → 返回错误信息
   - 路径3：用户被禁用 → 返回禁用提示
   - 路径4：登录成功 → 生成token

2. 权限验证流程
   - 路径1：无token → 返回401
   - 路径2：token过期 → 返回401
   - 路径3：权限不足 → 返回403
   - 路径4：权限通过 → 执行业务逻辑

```javascript
  })

```

### 8.2 后端自动化测试

**使用 JUnit + Mockito：**
```java
@SpringBootTest
@AutoConfigureMockMvc
class RunningControllerTest {
    
    @Autowired
    private MockMvc mockMvc;
    
    @Test
    @WithMockUser(username = "test", roles = {"STUDENT"})
    void testGetRunningStats() throws Exception {
        mockMvc.perform(get("/api/student/running/stats")
                .header("Authorization", "Bearer test-token"))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.code").value(200))
                .andExpect(jsonPath("$.data.totalDistance").exists());
    }
}
```
