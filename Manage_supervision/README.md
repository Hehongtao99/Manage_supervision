# 入侵检测统计分析系统

## 项目概述

入侵检测统计分析系统是一个专为网络安全设计的平台，用于检测、分析和统计网络入侵行为。系统支持用户、安全分析师和管理员三种角色，实现入侵检测、数据分析、报告生成和即时预警等功能。

## 主要特性

### 用户管理
- 多角色支持：管理员、安全分析师和用户角色
- 用户认证和授权
- 个人信息管理

### 课题管理
- 课题创建和分配
- 课题进度跟踪
- 课题评价和反馈
- 课题完成状态管理

### 任务管理
- 任务创建和分配
- 批量任务管理
- 任务截止日期设置
- 任务提交和审核
- 任务评价功能（评分和评语）

### 即时通讯
- 用户与安全分析师之间的即时消息
- 支持文件共享
- 未读消息提醒
- 消息历史记录

### 数据统计与仪表盘
- 管理员数据概览
- 安全分析师工作统计
- 用户进度统计

## 技术栈

### 前端
- Vue.js 3 + TypeScript
- Element Plus UI 组件库
- Pinia 状态管理
- Vue Router
- Axios HTTP 客户端
- SockJS + STOMP 用于WebSocket通信

### 后端
- Spring Boot
- Spring Security + JWT认证
- JPA + Hibernate
- MySQL数据库
- WebSocket 支持

## 安装与部署

### 数据库配置
1. 创建MySQL数据库
2. 使用以下SQL脚本初始化数据库：
   - `init_database.sql` - 初始化基础数据库结构
   - `add_supervisor_role.sql` - 添加安全分析师角色
   - `add_task_evaluation_table.sql` - 添加任务评价功能
   - `add_project_evaluation_table.sql` - 添加课题评价功能

### 后端配置
1. 进入backend目录
2. 配置`application.properties`文件中的数据库连接信息
3. 执行以下命令构建并运行后端服务：
```
mvn clean package
java -jar target/auth-0.0.1-SNAPSHOT.jar
```

### 前端配置
1. 进入frontend目录
2. 安装依赖：
```
npm install
```
3. 启动开发服务器：
```
npm run dev
```
4. 构建生产版本：
```
npm run build
```

## 常见问题与解决方案

1. **问题**: 登录后无法访问某些功能
   **解决方案**: 检查用户角色权限配置，确保用户被分配了正确的角色

2. **问题**: 文件上传失败
   **解决方案**: 检查上传目录权限，确保服务器有足够的存储空间

3. **问题**: 即时消息未实时显示
   **解决方案**: 检查WebSocket连接是否正常，可能需要刷新页面重新建立连接
