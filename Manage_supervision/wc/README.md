# 学生管理系统小程序端文档

本文档详细介绍了学生管理系统小程序端的架构和各个组件功能。

## 项目结构概览

小程序端采用微信小程序原生开发框架，主要用于家长查看子女学习情况、考勤记录和与教师沟通。主要包含以下模块：

```
wc/
├── app/                  - 小程序主应用目录
│   ├── config/           - 配置文件
│   ├── pages/            - 页面组件
│   │   ├── attendance/   - 考勤记录页面
│   │   ├── children/     - 子女信息页面
│   │   ├── grades/       - 成绩查询页面
│   │   ├── home/         - 首页
│   │   ├── homework/     - 作业查看页面
│   │   ├── login/        - 登录页面
│   │   ├── messages/     - 消息页面
│   │   ├── notifications/- 通知页面
│   │   ├── profile/      - 个人资料页面
│   │   └── register/     - 注册页面
│   ├── services/         - 服务层
│   ├── utils/            - 工具函数
│   ├── app.js            - 应用入口文件
│   └── app.json          - 应用配置
├── assets/               - 静态资源
├── pages/                - 全局页面
├── app.js                - 全局应用入口
├── app.json              - 全局应用配置
└── project.config.json   - 项目配置文件
```

## 核心文件说明

### 入口文件

#### `app.js`
- **功能说明**：小程序的全局入口文件
- **主要内容**：定义全局App对象，包含全局状态和方法
- **核心功能**：
  - 应用生命周期管理
  - 用户登录状态维护
  - 全局数据共享
  - 网络状态监听

#### `app.json`
- **功能说明**：小程序全局配置文件
- **主要内容**：定义页面路径、窗口样式、导航栏、底部标签栏等
- **核心配置**：
  - 页面注册与路径
  - 窗口样式设置
  - 底部标签栏配置
  - 网络超时设置

### 配置 (config)

#### `config.js`
- **功能说明**：应用配置管理
- **主要内容**：定义API接口地址、缓存键名、常量值等配置项
- **核心配置**：
  - 后端API基础URL
  - 静态资源路径
  - 缓存键名定义
  - 环境切换设置

### 工具类 (utils)

#### `request.js`
- **功能说明**：网络请求工具类
- **主要内容**：封装微信小程序网络请求API，提供统一的请求处理
- **核心功能**：
  - 请求拦截（添加令牌）
  - 响应拦截（统一错误处理）
  - 请求队列管理
  - 请求重试机制
  - 登录状态维护

#### `util.js`
- **功能说明**：通用工具函数集合
- **主要内容**：提供各种辅助功能的工具方法
- **核心功能**：
  - 日期格式化
  - 数据校验
  - 数据格式转换
  - 小程序接口Promise化
  - 存储数据管理

#### `moment.min.js`
- **功能说明**：日期处理库
- **主要内容**：提供强大的日期操作和格式化功能
- **核心功能**：
  - 日期解析和格式化
  - 日期计算
  - 相对时间展示
  - 日期国际化

### 服务层 (services)

#### `auth.js`
- **功能说明**：认证服务
- **主要内容**：处理用户登录、注册、身份验证等操作
- **核心功能**：
  - 用户登录
  - 用户注册
  - 微信授权登录
  - 令牌管理
  - 会话维护

#### `user.js`
- **功能说明**：用户服务
- **主要内容**：处理用户信息的获取和更新
- **核心功能**：
  - 获取用户信息
  - 更新用户资料
  - 修改密码
  - 用户设置管理

#### `message.js`
- **功能说明**：消息服务
- **主要内容**：处理家长与教师之间的消息交互
- **核心功能**：

  - 获取消息列表
  - 标记消息已读
  - 消息通知管理

#### `parent.js`
- **功能说明**：家长服务
- **主要内容**：处理家长特有功能，如获取子女信息、学习记录等
- **核心功能**：
  - 获取子女列表
  - 查询考勤记录
  - 查询作业情况

  - 与教师沟通

## 核心业务流程

### 用户认证流程
1. 用户打开小程序，检查本地存储的登录状态
2. 若无有效登录状态，跳转至登录页面
3. 用户通过账号密码或微信授权方式登录
4. 登录成功后获取并存储JWT令牌
5. 使用令牌调用获取用户信息接口，完成身份认证

### 子女信息查询流程
1. 用户登录成功后，自动获取已关联的子女列表
2. 在首页展示子女基本信息和学习概况
3. 用户可点击进入子女详情页面查看更多信息
4. 若有多个子女，可在界面中切换查看不同子女信息
5. 子女信息包括基本资料、班级信息、教师信息等

### 考勤查询流程
1. 用户进入考勤记录页面
2. 系统自动获取当月考勤数据
3. 以日历或列表方式展示考勤记录
4. 用户可筛选日期范围查看历史考勤
5. 对于缺勤记录，可查看详细原因说明

### 成绩查询流程
1. 用户进入成绩查询页面
2. 系统获取最近的考试成绩数据
3. 以卡片形式展示各科成绩和总评
4. 提供图表直观展示成绩分布和趋势
5. 支持按学期、考试类型筛选查询历史成绩

### 作业查看流程
1. 用户进入作业查看页面
2. 系统获取子女近期作业列表
3. 展示作业标题、科目、截止日期和完成状态
4. 用户可点击查看作业详情和教师批改意见
5. 对未完成作业可设置提醒通知

### 教师沟通流程
1. 用户进入消息页面，查看子女相关的教师列表
2. 选择特定教师进入聊天界面
3. 可发送文字、图片等形式的消息
4. 系统实时推送或定期拉取新消息
5. 支持查看历史聊天记录

## 实现细节

### 小程序授权机制
- 首次使用时申请必要的用户信息授权
- 明确说明授权用途，优化用户体验
- 提供授权失败的备选登录方式
- 合理管理授权状态，避免重复授权请求

### 缓存策略
- 合理使用本地存储缓存用户信息和认证令牌
- 对频繁访问但不常变更的数据进行缓存
- 实现缓存过期和更新机制
- 网络恢复时自动同步本地缓存数据

### 离线支持
- 关键数据本地缓存，支持离线查看
- 网络状态监听，自动恢复同步
- 离线状态下的用户操作队列
- 网络恢复后的数据冲突处理

### 性能优化
- 页面按需加载，减少冷启动时间
- 长列表使用虚拟列表优化渲染性能
- 图片懒加载和适当压缩
- 网络请求合并和优化
- 减少不必要的页面重渲染

### 用户体验优化
- 下拉刷新和上拉加载更多
- 骨架屏和加载动画减少等待焦虑
- 微交互反馈增强操作感知
- 表单校验即时反馈
- 适当的引导和提示

## 部署与配置

### 开发环境配置
- 使用微信开发者工具进行本地开发
- 通过`config.js`配置开发环境API地址
- 开发版本可使用测试账号快速登录
- 本地模拟数据支持离线开发

### 测试环境配置
- 使用体验版进行内部测试
- 连接测试环境API服务
- 配置测试环境专用域名和证书
- 支持真机预览和远程调试

### 生产环境配置
- 提交审核前确认生产环境配置
- 切换至生产API地址
- 移除测试代码和日志
- 优化小程序包大小和启动性能

### 版本发布流程
1. 开发完成后进行代码检查和测试
2. 配置生产环境参数
3. 上传代码并提交审核
4. 审核通过后发布新版本
5. 监控用户反馈和错误日志

## 扩展与维护

### 添加新功能
1. 创建新页面目录并编写WXML、WXSS、JS和JSON文件
2. 在`app.json`中注册新页面路径
3. 如需API交互，在`services`目录添加相应方法
4. 如需共享数据，在全局App对象或页面间通信中实现

### 版本迭代策略
- 小版本更新专注于bug修复和小功能调整
- 大版本更新引入新功能和界面改版
- 根据微信小程序规范管理版本号
- 设置合理的强制更新策略

### 数据安全与隐私保护
- 敏感数据加密存储
- 最小化权限请求
- 隐私政策明确且易于理解
- 用户数据本地化，减少不必要的云端存储
- 支持用户注销和数据清除

### 常见问题处理
- 会话过期自动重新登录
- 网络异常友好提示和重试
- 不兼容旧版本的优雅降级
- 异常崩溃的恢复机制
- 提供在线客服和反馈渠道
